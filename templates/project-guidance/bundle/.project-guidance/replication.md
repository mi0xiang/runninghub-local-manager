# 复刻启动与需求咨询

新视频先核对用户指定的原片、已有资料及目标，再用一次简短咨询对齐分析深度、范围、重点和保留程度。用户已有明确回答直接沿用，同项目接续读取记录；新视频重新对齐，用户也可以明确交由Codex判断。

| 可选深度 | 用途 |
|---|---|
| 概览拆解 | 看结构、主要内容和代表画面，判断借鉴方向 |
| 制作级拆解 | 对齐镜头、动作、台词与时间，支撑具体方案 |
| 精细对齐 | 对重点位置加密核对动作、声音与切镜 |

范围可以是全片、指定片段或全片加重点局部细拆，也可自由描述。用户选择后正式拆解；等待时可核对来源和已有资料，推荐项或未回复不算选择。这些是沟通选项，不绑定抽帧间隔、表格或技能。

口播可以保留轻改、采用已有稿库、重新创作或不使用，按本次目标选用；已有路线直接深化，不要求每次比较全部路线。采用哪种语言、如何换人换衣、哪些商品事实可用，从[本机项目资料](../.project-local/README.md)与用户要求核实；原片观察、制作建议与已验证商品事实分别表述。

用户给出视频及表格单元格时，保存二者的实际对应；Codex按需要定位内部ID。Lark等系统的字段、回写和责任分工逐步按用户需求明确，未定义的集成不阻塞本地制作或交付。操作外部系统仍核对本次授权与已采用接口。

后续按[子项目入口](child.md)自主推进；需要音画核对时参考[匹配要点](audio-visual.md)，H3分段执行查看[H3补充](h3.md)。
