# 子项目入口

遵循根[共同规则](../AGENTS.md)，从[本机上下文](../.project-local/README.md)定位自己的来源、实际项目和业务要求。单独目录的子项目也需要自己的可达入口；本文件不假定与管理器同盘或同目录。

接手时查用户目标、已有方案、批准、任务、交接和成果，接续确切断点。缺少来源时只询问具体缺项；内部标识由Codex根据用户提供的位置查找，不要求用户先填写整套内部字段。

新视频复刻按[需求咨询](replication.md)对齐颗粒度；已有明确回答直接沿用。其他制作从实际需求出发，不套用复刻咨询。

T恤复刻、展示和口播工作读取[T恤业务补充](tshirt-replication.md)及其指向的本机商品依据；其他业务按自己的本机指引开展。

目标明确后，自主安排拆解、素材、镜头、口播、提示词、后期与验证。先核对技能实际适用范围，再决定使用哪些技能；技能不可用时采用现有工具或说明缺口，不声称已经安装或执行。只有实质不同的方向才展示备选、差异和建议；用户已确定时直接落实。方案用能看懂结果的文字、关键图、对照或页面呈现，按任务需要确定细节。

改变已确认的成片方向、口播含义、关键商品内容，明显扩大范围，或改变上传/付费批次时，集中展示具体差异交用户决定。一般补查与本地修正由Codex处理。涉及音画对应时可参考[核对要点](audio-visual.md)，不强制表格或额外交付文件。

子项目负责从方案到完整交付，并检查目标、商品事实、可播放成片和实际偏差。未完成时，在现有项目方案/交接中留下版本、任务、验收证据、负责人、断点和下一步；总项目从同一记录跟踪，不另造汇报台账。实际执行接口要求的计划和批准结构依其文档保存，不以此限制创作方法。
