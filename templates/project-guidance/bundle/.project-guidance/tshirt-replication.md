# T恤复刻补充（仅该业务适用）

原片、对应单元格、商品知识及已有稿库从[本机上下文](../.project-local/README.md)定位；本文件提供通用协作提示，不附任何真实商品事实或来源。需求颗粒度仍按[复刻咨询](replication.md)由用户选择或明确交由Codex决定。

本套T恤复刻方案不采用`2-shot-director`；根据复刻任务选择合适工具或skill，其他业务不套用此限制，用户后续明确修改时同步调整适用指引。不得仅因为某技能能做分镜就认定它适合原片复刻。

衣服母版用于锁定外观，是否有人、如何换人换衣按原片结构及本次目标确定，不由素材拍摄方式代替决定。SKU、颜色、工艺、材质和性能依据实际已确认商品资料；待核实项不写成卖点事实。

口播可原片轻改、已有稿库适配、新写或不用，沿用已确认路线，不强制比较或调用某个稿库。镜头、展示部位、动作落点和口播时间按[音画参考](audio-visual.md)核对；稿库时长估计不能代替原片实测及本次要求。使用H3时按[H3补充](h3.md)分段和接续。

Lark按用户指定的视频与单元格逐步对接；内部ID由负责人按需要查找，不把旧表格结构、旧审批或旧任务参数套到新片。整片制作与交付仍由[子项目](child.md)负责。
