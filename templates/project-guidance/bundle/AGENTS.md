# 项目协作入口

总项目负责基本规则和项目跟踪；子项目负责自己的方案、执行、验收与完整交付。具体操作前读取[本机项目上下文](.project-local/README.md)，定位当前角色、项目资料和执行工具；按本次用户要求及已有确认接续。

## 共同边界

- 用户明确目标、颗粒度和重要选择后，Codex自主推进本地准备、工具选择和常规修正。按任务选用、组合或不使用skill；模板和示例供参考，不形成固定技能链。
- 上传、付费生成及失败重生成核对具体素材、参数、批次和次数的批准；已有批准在原范围内持续有效。工具选择不需要逐项批准，项目分配和安装不等于生成批准。
- 优先接续已有任务、批准及成果；未知提交先核对。活动项目由其负责人维护，共享状态通过现有协调入口更新，保留历史和可恢复断点。
- 以实际可核验的完整成果判定交付；登记并回读后进入待用户审核，最终确认绑定用户接受的准确版本。单个任务成功或技术检查通过不能代替完整交付。
- 本机路径、来源链接、商品资料、账号/资源标识、审批、日志和素材存本地私有目录。凭据通过环境变量或相应工具的凭据机制提供；只向公共仓库发布审阅过的通用程序、指引和合成示例。
- 运行方式按实际授权执行。项目跟踪不授权全天守护、系统计划任务、开机自启或自动创建/唤醒聊天。
