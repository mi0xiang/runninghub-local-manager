# 本机项目上下文（仅本地）

这份文件由模板初始化后保存在`.project-local/README.md`，不随Git上传。根据已有目录、配置和用户要求填写已知内容；不把每一项变成启动前问卷，缺项只在相关操作需要时询问。不要在此存API密钥或访问凭据。

- 本项目角色与目标：待按当前任务确定（总项目／单独子项目；同目录的制作子聊天直接读子项目入口）。
- 执行方式：待确定。使用H3管理器时启用通用指引中的H3补充；其他项目按自己的执行工具处理。
- 本机管理器位置：从当前机器查找。进入后读取其AGENTS、START_HERE及`.local/config.json`定位数据根。
- 项目与进度入口：填写实际项目目录、负责人及既有交接/跟踪入口；不用在这里复制整套台账。
- 来源资料：实际视频/文件/单元格及来源交接指引的位置；仅本机保存对应关系。
- 商品或专业依据：已经确认的知识文档位置，区分待核实内容。
- 专项业务指引：本项目对人物、语言、技能、内容等已确认要求和对应文件位置。仅适用于本项目，不写回公共模板。
- 共享协调：采用哪个唯一执行端/现有队列、共享登记入口；同账户多台机器须明确归属后再调度。
- 展示与验收：本项目页面/完整交付位置和已经确认的验收重点。

项目私有指引可以保存在本目录，或指向管理器仓库之外的数据根。新机器重新定位路径，真实来源和历史项目如需迁移由用户选择安全传输方式；Git只带来通用程序与模板。
