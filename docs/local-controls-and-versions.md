# 本机操作指引
## 程序与数据
程序来自代码仓库，所有生成记录保存在本机独立数据目录。此工具没有跨电脑数据同步，不部署 GitHub Pages，不开放局域网服务。
## 项目与队列
首页每页30个项目，按项目创建时间倒序，支持搜索和翻页。队列优先显示生成中和等待中；队列按序号排列，完成项按执行时间倒序。版本保留在原项目下，不覆盖原视频。
## 提交与失败
新项目、新批次、修改后的版本和失败重跑必须明确批准。素材哈希和批准清单需要匹配。未知提交结果禁止自动重提，有任务ID先查已有任务。工作流修改规则见代码仓库 docs/workflow-rules.md。
## 查询与接收
`dashboard` 手动启动只读展示，不查询云端。原任务收取使用 [project-runner](project-runner.md) 中有明确范围与退出条件的 `watch-results`；关闭后停止，重启接续。`tick` 会处理已批准队列，可能上传和提交；原有调度器常规查询从提交8分钟后开始，随后2分钟，下载由独立进程处理。共享并发上限3，使用同一FIFO与锁。
## 网页按钮
只读 `dashboard` 禁止操作型POST，不启动收片。以下按钮属于原有 `web` 入口：恢复会启动已批准队列；重新生成、Plus重跑需要准确付费批准；手动获取结果及该服务每2分钟的接收仅查询、下载已有taskId。`web` 启动前会渲染历史子页，使用前核对目标范围。打开视频不会生成新任务，停止本机服务不取消云端任务。
## 断点追踪
从项目 task_state.json、events.jsonl 和 approval.json 接手。有未知状态先核查平台。下载采用 .part 临时文件；中断后可能重新下载整个文件，不保证字节级续传。
## 初次导入
本版没有通用拖入工作流即运行的向导。由操作者或 Codex 按 docs/project-format.md 准备项目，完成本地复核并取得批准后接入队列。第三方工作流、模型及技能需要另行安装，不随公共程序分发。
